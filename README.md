# Shree Gauri

Production-ready Next.js website for Vercel.

## Deploy

1. Upload all files in this folder to the root of a GitHub repository.
2. Import that repository in Vercel.
3. Select the Next.js framework preset.
4. Leave Root Directory and Output Directory blank.
5. Deploy.

The storefront uses the existing Shree Gauri Supabase project for products,
categories, website settings, customer accounts, images and reviews.
